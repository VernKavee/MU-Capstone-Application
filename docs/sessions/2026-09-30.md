## Decisions

- Route: a Google Cloud VM from Vern's student credit, chosen over Vercel with Supabase
  cloud because similarity and feedback are both Python and need a host, and over the
  free plan's 50 MB per file.
- Build locally first and deploy near the end, with a phone test and one rehearsal deploy
  before the real one.
- Register without email confirmation. A free sslip.io hostname first; a bought domain is
  a later swap.
- The CLI stack never faces the internet with real testers' data: its secrets are
  Supabase's published demo values and it is built for local development. The commented
  `signing_keys_path` in `config.toml` was not checked. The VM runs the
  self-hosted Docker Compose with generated secrets, which reverses a Phase 1 consequence
  in ADR-0001 for the VM only.
- Everything is written as planned and pending, because Vern has asked the professor
  whether a public server is required at all.
