## Decisions made

- Tailscale Funnel for the evaluation tunnel; app on 443, Supabase API on 8443. ADR-0001.
- `npx supabase start` is the stack for both local and evaluation runs.
- Profile row created on form submit, so every column is NOT NULL and existence means
  complete. Section 8's "immediately after signup" is met by sending the user to the
  form straight after consent.
- Consent: one screen, three checkboxes, all required, declining signs out. Versioned in
  `lib/consent.ts`; a version bump forces re-consent.
- Consent, after Phase 1: a "Tick all three" button fills the boxes; Continue is still a
  separate click, so each consent stays an explicit tick. The old "I agree to all three"
  submit looked broken because native `required` validation blocked it silently.
- Firebase Auth was proposed again by a teammate and declined. ADR-0001 stands: every
  RLS policy keys off `auth.uid()`, so Supabase Auth is the identity for NFR2.
- Gate order: consent, then profile, then Home.
- Gender stored as text checked against female, male, other. Age 10 to 120, weight 20
  to 400 kg, height 100 to 250 cm, medical history 1 to 4000 characters.

## Facts worth remembering

- Next.js 16 renamed `middleware.ts` to `proxy.ts`, and route types come from
  `next typegen`; `tsc` fails on a fresh clone until it has run once (`next dev` also
  generates them).
- The Supabase changelog says new public tables are no longer exposed to the Data API by
  default, but the local CLI stack still grants everything to `anon` and `authenticated`.
  Without a delete policy, a delete silently affects zero rows. The migration revokes
  and re-grants explicitly so forbidden actions fail with a privilege error.
- `next/font/google` was removed from the layout so builds work offline.
- The local publishable key is the CLI's well-known development key, the same on every
  machine. `.env.local` is git-ignored anyway.
- The desktop browser pane sometimes reports a 0 by 0 viewport when hidden; page text
  and JavaScript evaluation still work, element refs do not.
