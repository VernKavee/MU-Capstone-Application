# 2026-10-11, the push-up on a portrait phone, and the replay's sync

Outside the build plan.

## Done

- Phone run on the Mac through two Cloudflare quick tunnels (ADR-0001, 2026-10-10), the app
  built against the API tunnel's address. Push-up with the phone's vertical video works
  (Vern).
- The replay's skeleton trailed the video. Cause and fix are in ADR-0005, "Amended
  2026-10-11": a constant start-up delay of the recorder, measured and removed in
  `replay.tsx`. Vern confirmed it in sync.
- Afterwards the tunnels, the app, and the stack were stopped.

## Next

  so the seek-to-the-end path is the one confirmed. A set recorded as mp4 (a Safari without
  webm) was not checked; its duration is finite, so the offset should be near zero.
- The offset is a shift; if a long set ever drifts, scale instead.
