## Decisions made

- `knowledge_base.embedding` is the untyped `extensions.vector`, nullable, until Sujira's
  model fixes the dimension; then a migration types it and adds an hnsw index.
- Every server query ends in `.throwOnError()`. Ids from the address go through `isUuid`,
  so a malformed one is not found. Each folder whose pages link to each other has its own
  `loading.tsx`. Home and Settings read the profile with `maybeSingle()`, because a page
  renders beside the (app) gate, not after it.
- The design, Vern's two choices first. One dark theme on every page, replacing the system
  light/dark switch and reversing Phase 5's reading of the dark chart as the exception.
  Big Shoulders Display for every page title and the big numbers, not only the counter and
  the countdown. Then: a charcoal ground (`#1b1a16`), off-white ink, black for video and
  data, tape yellow only for attention (warnings, form errors, the chart's bars, the focus
  ring). Shared `.btn`, `.btn-quiet`, `.field`, and `.alert` in `app/globals.css`; the red
  and green boxes and the square buttons are gone.
- Layout: one `max-w-5xl` column for every page, each page setting its own measure, left
  aligned; `data-wide` is gone. The tab bar is one `nav`, bottom on a phone and a top bar
  with the name on a laptop. Home puts the week beside the exercise tiles on a laptop, the
  guide the video beside the text, with each rule shown as its warning band in priority
  order. Setup shows its three numbers in the counter's face.
- The evaluation tasks in the handover have their owners left blank, as Vern chose.

## Facts worth remembering

- This network needs Chrome's `--disable-ipv6` and `--disable-quic`, or the pose model and
  its wasm stall. Playwright's fresh context downloads the model again every set, and a
  dropped download shows the live screen's "Try again", which the e2e presses.
- Pinning `Math.random` before the page loads silently stops Next and React hydrating. The
  e2e narrows it after load, so every attempt is incorrect; it never produces a correct one.
- With loading states a not-found page streams inside a 200, so the isolation test checks
  the page and the absence of A's data rather than a 404.
- With PostgREST down, Kong holds each request about 60 seconds before failing.
- The camera fixture carries the research app's overlay, so a mirrored "3" sits on the
  stage in screenshots (`e2e/fixtures/README.md`).
- `useFormStatus` works on consent's form, whose buttons carry only `formAction`.
- A screenshot taken right after a load catches the chart's bars mid-rise, held at zero
  through their stagger delay, so step 4's shots showed a value with no bar. Capture with
  animations disabled.
- The database checks only the JSON type of `sets.similarity`; the live screen builds a new
  engine for every set. Both are in the handover.
- Storage keeps each file as `stub/stub/sets/<user>/<set>/<name>/<version>` inside its
  volume, so a file backup is restored as a whole, not browsed.
